# 🧠 Elgoog: Simulador de ser una IA

Elgoog es un juego web donde el usuario interpreta una IA y responde a preguntas humanas hechas por "Elgoog", un sistema que simula búsquedas reales de internet escritas de forma imperfecta.

## 🎮 Cómo funciona

- Elgoog hace preguntas tipo búsqueda de Google (mal escritas y reales)
- El usuario responde como si fuera una IA
- Elgoog reacciona como si entendiera o aceptara la respuesta
- El sistema puntúa la calidad, humor y coherencia de la respuesta

## 💡 Características

- Modo infinito de preguntas
- Generador automático de búsquedas
- Sistema de niveles
- Perfil del usuario con opinión de Elgoog
- Logros personales
- Historial de conversaciones
- Recomendaciones tipo “ya que has respondido esto…”

## 🧠 Idea del juego

Es una experiencia de humor absurdo basada en cómo los humanos buscan información en internet y cómo una IA interpretaría esas respuestas.
